  # isitme-support

  This repository serves the support page and privacy     
  policy for **Is It Me or Is It Meno?**, an iOS app 
  that tracks perimenopause symptoms with all                                       
  data kept on the user's device. Advanced features
  to interact with hardware is planned.
                                                          
  The live pages are served via GitHub Pages:             
   
  - [Support](https://snilsen13-green.github.io/isitme-support/SUPPORT.html)                                                
  - [Privacy Policy](https://snilsen13-green.github.io/isitme-support/PRIVACY.html)
