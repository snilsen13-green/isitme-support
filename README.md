# isitme-support
                                                                                     
  This repository serves the support page and privacy policy for **Is It Me or Is It 
  Meno?**, an iOS app that tracks perimenopause symptoms with all data kept on the   
  user's device.                                                                  
                                                                                     
  ## Try the beta                                        
                 
  Public TestFlight beta: <https://testflight.apple.com/join/CeeAFTyN>
                                                                                     
  Install the TestFlight app from the App Store first, then tap the link on your
  iPhone to join.
